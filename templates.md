# PRD templates

Use these skeletons when drafting missing sections. Dual language in section titles where helpful. Mini-examples are illustrative and generalized.

---

## Strategy PRD template

```markdown
# [Initiative name] — Strategy & PRD

## 1. Frame the mission and the number (Charter)
**Mission:** …
**Value of one win:** …
**North star:** [baseline] → [target]
**Constraints:** …
**Candidate surfaces (provisional):** …

*Mini-example:* Mission: help new users complete foundational setup with AI + human help when needed. North star: assisted setup rate 12% → 30%. Value of one win: ~$X retained/expanded value per successful setup.

## 2. Ground the problem in research (Research-based problem)
**Qual evidence:** …
**Quant evidence:** …
**Prior research / experiment takeaways:** …
**Research-based problem (1–3 sentences):** …

*Mini-example:* Users say they want bite-sized help on their schedule; only a minority complete a long scheduled expert call; prior research shows avoidance when they “don’t know what to ask.”

## 3. Prove the problem (Problem stack)
**Overarching problem:** …
**Mad-libs problem statement:**
- I am …
- I am trying to …
- But …
- Because …
- Which makes me feel …
**Why current path fails:** …
**What worked / didn’t:** …
**Primary hypothesis:** …
```
